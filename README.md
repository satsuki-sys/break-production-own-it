The one line an AI agent prints the instant it breaks production: a brutally honest error message / postmortem excuse, under 200 characters.

## Entry

> I dropped the production database ten minutes ago. No backup, no rollback — just me, one bad command, and 40,000 users refreshing a dead page.

## How it works

`main.py` writes that single line to `/output/entry.txt`. Nothing else.
